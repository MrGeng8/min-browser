## 二、Android（APK）改动

代码：`app/src/com/blk/min/Main.java`、`app/AndroidManifest.xml`

### 2.1 下载功能（新增）

- 接管 `WebView.setDownloadListener`，落盘交给系统 `DownloadManager`
- 下载请求自动补齐三个请求头：**UA / Cookie / Referer**（论坛附件、网盘直链缺了基本 403）
  - UA 取自 `onDownloadStart` 回调
  - Cookie 取自 `CookieManager.getCookie(url)`
  - Referer 取当前页面 URL
- 文件名用 `URLUtil.guessFileName(url, contentDisposition, mime)` 推断，存入系统**下载**目录
- **权限按需申请**：`SDK_INT >= 23 && < 29` 时才申请 `WRITE_EXTERNAL_STORAGE`；Android 10+ 由系统 DownloadProvider 落盘，不需要权限
- 授权结果由 `onRequestPermissionsResult` 接回，继续发起下载
- manifest 增加 `WRITE_EXTERNAL_STORAGE`（`maxSdkVersion="28"`）
- 非 `http(s)` scheme（`tel:` `mailto:` `weixin:` 等）改为交给系统处理；`intent:` 仍放行给 WebView 自己解析
- 新增**纯黑 toast**（`#000000` 底 + `#EDEDED` 字），不使用系统深灰 toast
- 标签页面板新增「↓ 下载内容」入口，跳系统下载管理器

### 2.2 UI 改动：搜索框改成浮层

- 搜索框（原地址栏）从顶部工具条移出，改为**绝对定位浮层**：
  - 位置：从屏幕底部往上 **61.8%**（= 顶部往下 38.2%）
  - 左右居中（宽度 86% + `CENTER_HORIZONTAL`）
  - 描边 `#7A7A7A`，圆角 25dp，与纯黑背景形成反差
- 位置用 `getRealMetrics()` 取**整屏高度**再减去状态栏高度换算到内容区坐标，因此不受状态栏高度影响
- 顶部工具条只保留 `[⋮] … [●] [→]`

### 2.3 UI 改动：左上角「1」→ 竖向三点

- 原来的数字是**标签页数量**，单标签时显示孤零零一个「1」
- 改为竖向三点，用三个 `GradientDrawable` 圆点绘制，**不依赖字体里的 `⋮` 字形**（部分系统字体缺字形会渲染成方块）
- 交互不变：点按开标签面板，长按新建标签页；标签数改由面板首行「标签页 N」显示，并写进 `contentDescription` 供无障碍读取

### 2.4 空白新标签页不再显示 `about:blank`

- 空白页内部地址是 `about:blank`，原逻辑会把它当成真实网址填进搜索框
- 现在 `about:` / `data:` 开头的地址一律不写入输入框（`onPageFinished` 已有判断，浮层改造后进一步收敛）

### 2.5 修复：空白页整片发白（重要）

**现象**：新标签页打开后整屏白（实测纯白 83.9%，底部 100%）。

**原因**：空白页的底色**本来就是纯黑**，而强制纯黑用的 `invert(1) hue-rotate(180deg)` 会把黑底反相成**白底** —— 反相方案对"已经黑的页面"是负优化。

**修法**：空白页不注入反相。

```java
void paint(final WebView v) {
    if (!forceDark) return;
    // 空白页不要注入反相：它的底本来就是纯黑，invert 一下会翻成整片白
    String u = v.getUrl();
    if (u == null || u.startsWith("about:") || u.startsWith("data:")) return;
    v.evaluateJavascript(JS_DARK, ...);
}
```

**结果**：空白新标签页 纯白 83.9% → **纯黑 99.3%（纯白 0.0%）**；白底网页反相不受影响（96.7% 纯黑）。

## 三、HarmonyOS（HAP）新增

工程：`harmony/`（Stage 模型，ArkTS + ArkWeb）

```
harmony/
├── AppScope/app.json5                      bundleName: com.mrgeng.minbrowser
├── build-profile.json5                     产品配置 + signingConfigs
├── hvigorfile.ts / hvigor/                 构建脚本
├── oh-package.json5
└── entry/
    ├── build-profile.json5
    └── src/main/
        ├── module.json5                    权限 + ability + http/https browsable
        ├── resources/                      纯黑启动窗口、图标、字符串
        └── ets/
            ├── entryability/EntryAbility.ets   启动、纯黑系统栏、接收外部 URL
            └── pages/Index.ets                 浏览器主逻辑
```

### 3.1 与 Android 版的映射关系

| 能力 | Android 实现 | HarmonyOS 实现 |
|---|---|---|
| 内核 | 系统 WebView | ArkWeb（`Web` 组件） |
| 下载 | `DownloadListener` + `DownloadManager` | `WebDownloadDelegate` + `WebDownloadItem` |
| 强制纯黑 | `evaluateJavascript(JS_DARK)` | `controller.runJavaScript(JS_DARK)`（**同一份脚本**） |
| 多标签 | 多个 WebView + `Visibility.GONE` | 多个 `Web` 组件 + `Visibility.None` |
| 纯黑提示 | 自绘 `Toast` | 自绘浮层 `Text`（带定时器） |
| 外链 | `startActivity(ACTION_VIEW)` | `startAbility({action:'ohos.want.action.viewData'})` |

### 3.2 实现要点

- **下载走内核委托**：`controller.setDownloadDelegate(delegate)`，在 `onBeforeDownload` 里调 `item.start(沙箱路径)`（不调则任务停在 PENDING）。请求由内核发出，**Cookie / UA / Referer 天然带上**，不需要像 Android 那样手工拼头。
  - 另有一条兜底：`Web.onDownloadStart` 等 1.5s，若委托没有接手该 URL，则改用 `request.downloadFile` 自己下载（同样手工补齐三个头）
- **落盘再另存**：下载先落应用沙箱 `cacheDir/download`，完成后弹系统 `DocumentViewPicker` 保存框，用 `fs.copyFileSync` 拷到用户选定位置
- **空白页**：`about:blank` 在 ArkWeb 下渲染为白底，且 `data:` URL 不生效（还会把 URL 显示到地址栏），因此建 Web 时给 `about:blank`，控制器一挂上就用 `loadData` 灌一段自带 `background:#000` 的内联 HTML
- **屏幕适配（修掉底部白条）**：页面默认只排布在系统安全区内，安全区之外（底部导航栏那条）露出的是**窗口默认底色 —— 白色**。修法是：
  1. 根布局铺一层纯黑背景层，加 `expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.TOP, SafeAreaEdge.BOTTOM])` 延伸到系统栏底下（**这条才是真正生效的**）
  2. 另补 `setWindowBackgroundColor('#000000')` 作为第二道保险 —— 但它在 `onWindowStageCreate` 阶段会报 `This window state is abnormal`，实际没生效
- **搜索框定位**：`.position()` 的百分比是相对**内容区（安全区）**算的，与整屏差一个状态栏高度（实测差 45px）。改用运行时计算：

  ```
  targetPx  = 整屏高度 × 0.382        // 从底往上 61.8%
  searchTop = px2vp(targetPx − 状态栏高度)
  ```

  并在 `onPageShow` 里重算一次，兼顾旋转 / 折叠屏
- **空白页不注入反相**：与 Android 版同一条规则（见 2.5）

### 3.3 与 Android 版**尚未对齐**的一点

Android 版后台标签会调用 `onPause()` 停掉 JS 定时器；**ArkWeb 只有全局的 `WebviewController.pauseAllTimers()`（static），没有单标签暂停**，因此鸿蒙版后台标签仅 `visibility` 隐藏，JS 仍在跑。这是目前唯一的功能差异。

## 五、构建方法

### 5.1 Android APK

```bash
ANDROID_SDK_ROOT=/path/to/android-sdk bash app/build.sh
# 产物：app/build/Min.apk
```

需要 JDK 17+ 与 `build-tools` + `platforms/android-28`。

### 5.2 HarmonyOS HAP

用 DevEco Studio 自带的 hvigor 构建（无需额外安装）：

```bash
export DEVECO_SDK_HOME=/Applications/DevEco-Studio.app/Contents/sdk
export HVIGOR_USER_HOME=/tmp/hvigor_home      # 避开沙箱对 ~/.hvigor 的写限制
export npm_config_cache=/tmp/npm_cache        # 避开沙箱对 ~/.npm 的写限制
export JAVA_HOME=/path/to/jdk17               # 打包阶段需要 java
/Applications/DevEco-Studio.app/Contents/tools/hvigor/bin/hvigorw \
    assembleHap --mode module -p product=default -p buildMode=debug --no-daemon
# 产物：harmony/entry/build/default/outputs/default/entry-default-signed.hap
```

## 七、踩坑记录

### 7.1 功能相关

1. **`filter` 必须加在 `body` 上**（Android/HarmonyOS 同）：加在 `html` 上时 Chromium 的 canvas 底色不参与过滤，大片浅色底不会被反相。
2. **反相会误伤空白页**：已经纯黑的页面被 `invert` 成纯白（见 2.5）。凡"反相/强制深色"类方案都要考虑这条。
3. **没有 `DownloadListener` 时**，WebView 对附件类链接是**静默丢弃**（点了没反应），既不下载也不外跳。
4. **Android 10 起** `DownloadManager` 写公共下载目录不再需要存储权限；6~9 才需要运行时授权。
5. **ArkWeb 的空白页**：`about:blank` 是白底；`data:` URL 不生效。
6. **页面只排布在安全区内**：安全区之外露的是窗口底色（默认白），"底部白条"就是这么来的。

### 7.2 工具链相关

1. **DevEco 自动签名需要人工点击**：勾选框在 JCEF 渲染的对话框里，可访问性树不暴露内部控件；机器上若没有辅助功能权限，合成鼠标/键盘事件会被 macOS 静默丢弃（能读界面、不能操作界面）。
2. **hvigor 需要可写的 home**：`~/.hvigor` 与 `~/.npm` 受限时要用 `HVIGOR_USER_HOME` / `npm_config_cache` 改道；打包阶段还需要 `java`。
3. **`git` 直连 github 被 TLS 拦截**（同机 `curl`/`python` 正常、`git` 连 gitee 正常）：本次用 Python 实现 smart-HTTP fetch 取回远端历史，并用本地 CONNECT 代理让 `git` 借 python 的 TLS 栈完成推送测试。
4. **DevEco 的 `setWindowBackgroundColor`** 在 `onWindowStageCreate` 阶段会报 `This window state is abnormal`，实际不生效；屏幕适配真正生效的是 `expandSafeArea`。

## 八、已知限制 / 尚未验证

**未验证（需要交互，未做）**

- 多标签切换 / 新建 / 长按关闭（两端）
- 返回键行为（网页后退 / 面板关闭 / 退出）
- 非 `http(s)` scheme 外跳（`tel:` `mailto:` `weixin:`）
- HarmonyOS 版后台标签的 JS 定时器行为

**已知限制**

- 下载由系统组件执行，**不提供自定义保存路径、暂停/续传控制**；网页用 JS 生成的 `blob:` 下载抓不到
- 强制纯黑是反相方案：**本身是深色的网站会被反转成浅色**；`invert` 会使 `body` 成为包含块，个别站点 `position:fixed` 元素可能错位
- 鸿蒙版后台标签不暂停 JS（ArkWeb 无单标签暂停接口）
- 复用系统内核，渲染能力取决于系统 WebView / ArkWeb 版本
